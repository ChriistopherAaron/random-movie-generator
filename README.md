# 🎬 Random Movie Generator

A lightweight, interactive web application designed to eliminate decision fatigue on movie nights! Whether you're planning a cozy date night with your partner or hanging out with friends, simply add your movie ideas, hit randomize, and let the app pick tonight's feature.

---

## 🚀 Features

- **Dynamic Queueing:** Add movie titles on the fly to build a custom watchlist.
- **Easy Removal:** Remove individual titles easily in case of typos or changed minds.
- **Randomized Selector:** Instantly selects a winner from your list using JavaScript math logic.
- **Modern Responsive UI:** Features a centered modal layout, sleek dark background, and clean typography designed with CSS Flexbox.

---

## 🛠️ Technical Stack & Web Concepts

Built to demonstrate core front-end development principles and DOM manipulation techniques:

* **HTML5:**
  * Semantic layout structure using `<main>`, `<section>`, and `<header>` tags.
  * Form controls using `<input>` with `type="text"` and placeholder attributes.
  * Unordered list structure (`<ul>` and `<li>`) for dynamic content rendering.

* **CSS3:**
  * Modern **Flexbox** (`display: flex`, `justify-content`, `align-items`) for centering and component alignments.
  * Custom box styling using `box-shadow`, `border-radius`, and `min-height: 100vh`.
  * Dynamic hover effects (`:hover`) and smooth color transitions.
  * Interactive scroll behavior using `overflow-y: auto` and `max-height` containers.

* **JavaScript (ES6):**
  * **DOM Manipulation:** `document.getElementById()`, `createElement()`, `appendChild()`, and `remove()`.
  * **Event Handling:** `addEventListener()` attached to button triggers.
  * **Array Management:** Storing user inputs in arrays and manipulating list items using `.push()`, `.indexOf()`, and `.splice()`.
  * **Randomization Logic:** Utilizing `Math.floor(Math.random() * array.length)` for index selection.
